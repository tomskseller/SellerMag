# Структура Google Таблицы

Таблица — рабочая панель менеджера. Менеджер правит остатки/цены в листе
«Остатки», сайт читает их через сервисный аккаунт Google Sheets API и
синхронизирует в Supabase. Новые заказы из Supabase автоматически дописываются
в лист «Заказы» — менеджеру не нужно ничего скачивать/загружать вручную.

## Лист «Остатки»

| Колонка       | Пример              | Комментарий                              |
|---------------|---------------------|-------------------------------------------|
| SKU           | KP-BEL-2432-60      | Уникальный артикул, ключ синхронизации     |
| Категория     | Курьерские пакеты   |                                             |
| Товар         | Курьерский пакет белого цвета | Название карточки товара        |
| Размер        | 24x32               |                                             |
| Плотность,мкм | 60                  |                                             |
| Цена, ₽       | 4.2                 | Цена за штуку (базовая, до опта)           |
| Остаток, шт   | 820                 | Обновляется менеджером вручную             |
| Активен       | TRUE / FALSE        | Скрыть товар с сайта без удаления строки   |

## Лист «Опт»

| Колонка     | Пример | Комментарий                          |
|-------------|--------|----------------------------------------|
| SKU         | KP-BEL-2432-60 | Ссылка на строку в листе «Остатки» |
| От, шт      | 100    | Порог количества                       |
| Цена, ₽/шт  | 3.78   |                                         |

## Лист «Заказы» (пишет сайт, менеджер только читает)

| Колонка          | Пример                     |
|------------------|----------------------------|
| Дата/время       | 2026-08-17 14:32           |
| № заказа         | СМ-48213                   |
| ФИО              | Марина Соколова            |
| Телефон          | +7 999 123-45-67           |
| Способ доставки  | Курьер по городу           |
| Плательщик       | Физлицо / Юрлицо (ИНН)     |
| Статус оплаты    | Оплачен / Выставлен счёт   |
| Состав заказа    | KP-BEL-2432-60 × 300; ...  |
| Сумма, ₽         | 1140                       |

## Синхронизация

- **Остатки → Supabase**: фоновая задача на backend (cron раз в 2-5 минут или
  по кнопке «Обновить» в будущей админке) читает лист «Остатки» и «Опт» через
  Google Sheets API и обновляет таблицы `product_variations` и
  `wholesale_tiers`.
- **Заказы → Google Таблица**: при создании заказа backend сразу же (webhook,
  не по расписанию) дописывает строку в лист «Заказы» через Google Sheets API
  и помечает заказ `sheet_synced = true`.
- Доступ к таблице — через сервисный аккаунт Google (JSON-ключ), таблица
  открывается ему на редактирование по email сервисного аккаунта.
